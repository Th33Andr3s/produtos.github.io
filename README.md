# produtos.github.io
Este proyecto es una página web que muestra una lista de productos de cuidado personal. El objetivo es mostrar el diseño y la funcionalidad de una página web para una tienda online.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Estructura del proyecto
- index.html: es la página principal de la aplicación.
- styles.css: es el archivo de estilos CSS que define la apariencia de la página.
- scripts.js: es el archivo de JavaScript que agrega interactividad a la página.

## Funcionalidad
La página web muestra una lista de productos de cuidado personal.
